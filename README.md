# NC Elections Lab — MVP (Milestone-1)

Demo-ready scaffold: **React (Vite) + MUI + React Router + React Query + Leaflet** on the client, and **Express** on the server. This milestone delivers the site shell, theming, routing, and a Geoportal page with an OSM basemap centered on North Carolina (no data layers yet).

## Tech Stack

- **Frontend**: React (Vite), React Router, MUI with custom theme, React Query, Leaflet (react-leaflet)
- **Backend**: Node.js (>= 20.19.0), Express, CORS
- **Quality**: ESLint + Prettier
- **Deploy**: Render (separate client + server services)
